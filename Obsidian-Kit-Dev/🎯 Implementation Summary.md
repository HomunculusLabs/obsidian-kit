## 🛠️ CLI Commands Available

### 📋 Task Management
```bash
obsidian-kit breakdown "task description"     # AI task breakdown
obsidian-kit validate --all                   # Quality validation
obsidian-kit generate-tasks                   # Automated generation
obsidian-kit status                           # System status
```

### ⚙️ Workflow Automation
```bash
obsidian-kit workflow spec-driven             # Spec-driven development
obsidian-kit workflow interactive             # Interactive mode
obsidian-kit workflow enhanced                # Enhanced workflows
```

### 🔍 Knowledge & Search
```bash
obsidian-kit semantic-search "query"          # Semantic search
obsidian-kit knowledge-graph --visualize      # Knowledge graph
obsidian-kit learning-capture --analyze       # Learning analysis
```

### 🤖 AI & Intelligence
```bash
obsidian-kit enhanced-agent enhance           # Agent enhancement
obsidian-kit enhanced-agent analyze           # Context analysis
obsidian-kit ai-tasks --insights              # AI insights
```

### 🛠️ Development
```bash
npm run dev-setup                             # Environment setup
npm run check-quality                         # Quality checks
npm test                                      # Run tests
npm run deploy:production                     # Deploy to production
```
