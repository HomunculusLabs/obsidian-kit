## 🔌 Essential Obsidian Plugins

### 🎯 Core Functionality

#### **Dataview**
- **Purpose**: Query and display vault data dynamically
- **Features**: SQL-like queries, inline queries, data visualization
- **Integration**: Works seamlessly with Obsidian Kit task management
- **Installation**: Community Plugins → Search "Dataview"
- **Configuration**: Enable JavaScript queries for advanced functionality

#### **Templater**
- **Purpose**: Powerful template creation and automation
- **Features**: JavaScript functions, system commands, user functions
- **Integration**: Used by Obsidian Kit for template generation
- **Installation**: Community Plugins → Search "Templater"
- **Configuration**: Enable system commands and user functions

#### **Tasks**
- **Purpose**: Advanced task management in markdown
- **Features**: Task scheduling, dependencies, recurring tasks
- **Integration**: Complements Obsidian Kit's task system
- **Installation**: Community Plugins → Search "Tasks"
- **Configuration**: Configure date format and task symbols

#### **Calendar**
- **Purpose**: Visual calendar integration with daily notes
- **Features**: Monthly view, navigation, task integration
- **Integration**: Works with daily note workflows
- **Installation**: Community Plugins → Search "Calendar"
- **Configuration**: Connect to daily notes folder

#### **Kanban**
- **Purpose**: Visual task boards and project management
- **Features**: Drag-and-drop, lanes, card templates
- **Integration**: Visualize Obsidian Kit tasks
- **Installation**: Community Plugins → Search "Kanban"
- **Configuration**: Set up default lanes and templates

### 📊 Data & Analytics

#### **Tracker**
- **Purpose**: Track metrics and habits over time
- **Features**: Graphs, charts, goal tracking
- **Integration**: Monitor project progress and personal metrics
- **Installation**: Community Plugins → Search "Tracker"
- **Configuration**: Define custom tracking metrics

#### **QuickAdd**
- **Purpose**: Rapid content creation and capture
- **Features**: Multi-choice, templates, macros
- **Integration**: Quick task and note creation
- **Installation**: Community Plugins → Search "QuickAdd"
- **Configuration**: Set up capture workflows

#### **Commander**
- **Purpose**: Add commands to various UI elements
- **Features**: Custom commands, UI customization
- **Integration**: Quick access to Obsidian Kit commands
- **Installation**: Community Plugins → Search "Commander"
- **Configuration**: Add Obsidian Kit commands to ribbon

## 🤖 AI & Automation Tools

### 🧠 AI Assistants

#### **Claude Desktop**
- **Purpose**: Anthropic's AI assistant for development
- **Features**: Code analysis, documentation, problem-solving
- **Integration**: Native Obsidian Kit agent support
- **Setup**: `obsidian-kit agent add claude-code`
- **Configuration**: Configure API key and model settings

#### **OpenCode**
- **Purpose**: AI-powered VS Code integration
- **Features**: Code completion, inline suggestions, debugging
- **Integration**: Enhanced development workflow
- **Setup**: `obsidian-kit agent add opencode`
- **Configuration**: Connect VS Code workspace

#### **Cursor**
- **Purpose**: AI-first code editor

## 🛠️ Tool Configuration Templates

### 📋 Obsidian Plugin Configuration

```yaml
# Essential plugins for Obsidian Kit
plugins:
  enabled:
    - dataview
    - templater
    - tasks
    - calendar
    - kanban
    - quickadd
    - commander
    - obsidian-git
    - tag-wrangler
    - advanced-tables
  
  dataview:
    enableInlineQueries: true
    enableJavaScriptQueries: true
    renderNullAs: "-"
  
  templater:
    enableSystemCommands: true
    enableUserFunctions: true
    userScriptsFolder: "scripts"
  
  tasks:
    autoSuggestInEditor: true
    provideAccessKeys: true
    useFilenameAsScheduledDate: true
```
